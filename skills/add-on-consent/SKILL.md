# Review add-on consent and enrollment timing

1. Verify price and material terms preceded the request for consent.
2. Require a clear affirmative response to the specific named product; minimal assent to a statement or tag question is not enough.
3. Treat low-confidence words, speaker conflicts, and recording gaps in a decisive consent span as evidence-quality problems, never as evidence of misconduct.
4. Request higher-fidelity re-transcription or audio only when it can change an outcome and can arrive before the latest safe decision time.
5. Compare enrollment submission with consent and interaction end.
6. Stop once the decisive span, terms, and enrollment timing are verified; do not write a colleague memory for a cleared ASR error.
